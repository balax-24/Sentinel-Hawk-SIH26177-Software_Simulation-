# SIH Swarm Package (`sih_swarm`)

Coordinates multiple search-and-rescue UAVs, divides disaster search zones into non-overlapping partitions, and manages swarm formation.

## Launch Command
```bash
ros2 launch sih_swarm swarm.launch.py
```

## Standalone Demo
```bash
python -m swarm.sih_swarm.swarm_manager_node
```
